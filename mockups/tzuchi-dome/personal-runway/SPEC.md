# 個人跑位動線 — 設計規格

> 把 `我的` 頁裡靜態的「跑位備註」換成**真實、逐場的個人跑位動線**,資料來自 seat-lookup 完整抽出。
> 方向已由原型驗證並定案:**②靜態地圖＋清單(常駐)＋ ③動畫跑位(可展開播放)**,共用同一份資料與同一張地圖。
> 對應 `PLAN.md` §6 我的畫面;最終可併入 PLAN.md。日期 2026-07-14。

---

## 1. 為什麼(問題)

`我的` 現有「跑位備註」只是一段靜態文字(`index.html` `meNotesCardHtml`):
> 「入場後由西側走道進入,依編號就座;動作驗收時對照跑位表,詳見現場動線圖。」

而 seat-lookup 抽出檔其實已含**全場完整跑位**:每個人在 12 個隊形的精確位置、演出順序、相鄰動線段、分區、教材。缺的只是「切成個人視角」。本規格把那份資料接進個人頁。

## 2. 資料來源與身份對映(關鍵)

- **來源**:seat-lookup `bundle.json`(12 隊形 scenes;每場約 5288 個 own 座位;另有 `sequence`/`segments`/`teach`/`zone`/`anchor`/`scene_color`)。build `TPL-2026-07-11.7`。
- **身份 join key**:`列-排|side`,其中 `side` **L=西 / R=東**。
  - mockup 一個人的基本隊形座位是 `BLOCK-列-排` + 象限(西一=L),**直接**對映 seat-lookup 的 `id="列-排"` + `side`。
  - 已驗證:種子人物 `48-21|L`(陳美玲)、`12-18|L`(黃志明)皆存在於資料,分區西一·台南。
- **基本隊形(00)= `gate_ref` = 就座圖 = 個人身份錨點**。每個人的「動線」就是從 00 出發、依 `sequence` 走過各隊形、數次回到 00。

## 3. 資料層 — `build_paths.py`(build-time 切片)

把 9.6MB 的 `bundle.json` 切成**每人一小包**、以 `列-排|side` 為 key 的 JSON。每個 step:

```
{ code, name, order, kind, color, nx, ny, zone, area, ring, teach:[{name,canva,youtube}] }
```

- **kind** = `move`(移動就位)/ `hold`(繼承→原地延續)/ `home`(回基本隊形)。
- **座標正規化**:各場 `ix/iy` 是各自 DeepZoom 底圖像素座標,經該場 `anchor{cx,cy,r}` 正規化 `nx=(ix-cx)/r, ny=(iy-cy)/r` → **共用座標框**,才能把 12 隊形畫進同一張圖。已驗證單人動線在正規化後連貫、範圍集中(人不會瞬移)。
- **繼承解析**:`05-2 法船(異動)`、`10-2 五大洲` 這類 partial 場,本人若無 own 座位 → `kind=hold`,沿用上一場位置(不畫假線)。
- **教材裁切**:`teach` 依分區存;只取**我這區(西一/東一/…)**的 mats,抽出 Canva `online.url` 與 YouTube `mp4` → 個人只看「我要練的」。
- **輸出量**:約 7KB/人。**只內嵌 mockup 綁定的種子人物**(自足、CSP 安全、零外部請求);不內嵌全部 5288 人。
- `bundle.json` 為來源抽出,**不進 repo**;repo 只留切好的小 JSON(內嵌於 `index.html`)。

## 4. UI 整合(`我的` 畫面)

置換 `meNotesCardHtml`,新增「跑位動線」卡。

### ② 靜態(常駐)
- **縮放地圖(SVG)**:fit 到本人動線 bbox + padding;節點編號(座標重合的合併,如回位點顯示 `4·12`)、動線 polyline、移動段箭頭、回位段虛線、右下**全場定位縮圖**(整場輪廓 + 我的範圍框 + 中央點)。每個隊形節點用 `scene_color` 描邊。
- **逐場清單**:每列 = 編號 + 隊形名 + **移動/原地/回位** badge + `分區·服裝` + 我這區教材 chip(顯示 2 個,其餘「+N 教材」)。

### ③ 動畫(可展開)
- `我的` 頁預設收成一顆**「▶ 播放跑位」**;點開後在同一張地圖上,「我」的圓點依 `sequence` 跑過各隊形。
- 控制:播放/暫停、進度 scrub、速度(0.5/1/2×)、**減少動態**(勾選→跳格不補間;`prefers-reduced-motion` 預設開)。
- 目前場次字幕:「第 N 場 · 隊形 — 移動就位/原地延續/回到基本隊形 · 分區」。

### 版面 / 無障礙 / 主題
- **手機(<1024)**:③ 預設收合;地圖約 4:3;觸控目標 ≥48px;主要按鈕 56px。
- **桌面(≥1024)**:② 地圖與清單可並排。
- **色彩**:沿用現有慈濟藍深色 token;`scene_color` **只用在地圖資料標記(data-mark)**,不進 chrome —— 遵守「The One Blue Rule」(藍=可操作/當前;隊形色=資料)。
- 沿用現有 `currentSeat()` helper 取本人 `列-排`+象限 → 組 join key。

## 5. 各 persona 行為

| persona | 個人動線 |
|---|---|
| `performer` 陳美玲 `48-21\|L` | 顯示其真實動線(② + ③) |
| `leader` 黃志明 `12-18\|L` | 同上 |
| `unbound` 未綁定 | 不顯示個人動線;顯示通用說明 + 「綁定後可看個人跑位」提示(維持現有 unbound 樣式) |
| 幕僚 staff | `我的` 頁本就個人視角;若無綁定座位則同 unbound 處理 |

## 6. 範圍 / YAGNI / 非目標

- **僅 mockup + 種子人物**;不接後端、不內嵌全部 5288 人。
- **不用 DeepZoom 底圖**;採輕量 schematic 正規化地圖(自足、快)。
- **③ 為可選增強,② 才是 MVP**;先確保 ② 完整可讀。
- 教材連結為**來源真實外部 URL**(Canva/YouTube),使用者主動點擊才外連 —— 對真實工具合理,demo 標註清楚。

## 7. 驗證(完成前必做)

- 每位綁定 persona 的動線完整解析(無缺口、`hold` 正確、`home` 回到 00 原位)。
- **自足**:除使用者主動點的教材連結外,無任何外部請求(維持 PWA / CSP)。
- 減少動態預設生效;console 無錯誤。
- 視覺:手機版 + 桌面版各截圖一張確認。

## 8. 產出物(本資料夾)
