Scroll-triggered motion

Reveal content the moment it enters the viewport

An IntersectionObserver-based scroll reveal system. Elements fade, rise, and sharpen into focus once—no scroll jank, no re-triggering.

See it in action
Features

Built for calm, cascading reveals

Each card below is observed independently and animates in with a slight stagger as you scroll past this section.

Threshold 0.2

Elements trigger once 20% of their area is visible in the viewport.

Negative root margin

A -10% bottom margin means reveals feel intentional, not premature.

Fires once

Observer unobserves each element right after it animates in.

Blur to focus

An 8px blur resolves to zero alongside the opacity and translate.

Workflow

How the reveal pipeline works

A simple four-step loop keeps this system lightweight, no animation libraries required.

01

Mark elements

Add the animate-on-scroll class to any element you want to reveal.

02

Observe

An IntersectionObserver watches every marked element on the page.

03

Toggle the class

Crossing the threshold adds .animate, unpausing the keyframe.

04

Unobserve

The element is removed from observation so it never re-animates.
