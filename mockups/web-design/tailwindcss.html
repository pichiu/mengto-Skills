Handling dynamic classnames safely

Never build class names by concatenation — Tailwind's scanner can't see "bg-" + tone. Map to a fixed set of literal classes instead.

Live example — click to change tone

Success 
const toneClass = {
  success: "bg-emerald-600",
  danger: "bg-rose-600",
  info: "bg-sky-600",
}[tone];

el.className =
  `inline-flex items-center gap-2 rounded-xl
   px-4 py-2 font-medium text-white ${toneClass}`;

Common pitfalls

Classes missing in production

Make sure the content/globs config includes every template and component file, or unused-looking classes get purged.

Overusing @apply

Prefer component composition first. Reach for @apply only for small, truly repeated patterns.

Assuming class order wins

Conflicting utilities aren't resolved by source order alone — be explicit and avoid stacking contradictory utilities.

Huge class lists, no structure

Break markup into subcomponents, or use clsx/cva to manage variants instead of one 300-character class attribute.
