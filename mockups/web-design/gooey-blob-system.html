Why it works

One soft system, many places to use it

The same blur-and-threshold trick powers a hero atmosphere, a playful loader, and small cursor accents — all from one filter definition.

🌊

Hero atmosphere

Large drifting blobs behind headline copy give the page a calm, breathing backdrop without stealing focus from the message.

🔗

True merging

Gaussian blur softens edges, then a high-contrast color matrix snaps alpha back to solid — so overlapping shapes fuse into one mass.

🧊

Reduced-motion safe

When motion is disabled, blobs freeze into a pleasing static arrangement — the gooey merge is still visible, only the drift stops.

Same filter, smaller scale

A compact instance of the blob system works well as a loading indicator or a fun accent tucked into a card or empty state.

  • Keep blur and contrast values shared across instances for visual consistency.
  • Slow, smooth easing — never fast or jittery — keeps the motion cohesive.
  • Fewer, smaller blobs at reduced scale still read as one continuous shape.
